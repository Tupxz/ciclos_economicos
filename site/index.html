Estructura recomendada para site/

Para que los links de arriba funcionen, se espera algo así dentro de site/:

  • site/reportes/: HTML/PDF exportados desde el notebook
  • site/outputs/: copia (o links) de outputs/ para ver tablas/figuras en la web

Nota: GitHub Pages sirve archivos estáticos. Para que “outputs” se vean desde la web, deben estar dentro de site/ (o enlazados de forma compatible). Si quieres, te digo la forma más limpia de “copiar solo lo necesario” sin duplicar medio repo.

Si algún link da 404, normalmente es porque el archivo no está dentro de site/ (para Pages) o el nombre no coincide exactamente.
