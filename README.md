# Ciclos Económicos EAFIT

Profesor: Álvaro Hurtado Rendón  
Autor: Santiago Tupaz  

Repositorio para la materia **Macroeconomía 3: Ciclos Económicos**, enfocado principalmente en la realización de las actividades de seguimiento, talleres y desarrollos cuantitativos del curso.

## Sobre la materia

Este curso estudia los ciclos económicos desde una perspectiva moderna y microfundamentada. A lo largo del semestre se trabajan modelos dinámicos de consumo y ahorro, equilibrio general en economías de dotación y producción, política fiscal, política monetaria y algunos enfoques sobre fluctuaciones macroeconómicas.

El enfoque combina teoría económica, modelación matemática y análisis empírico con datos reales.

## Propósito del repositorio

Este repositorio tiene como objetivo:

- Desarrollar y documentar las actividades de seguimiento.
- Implementar los modelos vistos en clase.
- Realizar ejercicios empíricos con datos macroeconómicos.
- Organizar código, bases de datos y resultados.
- Consolidar el trabajo del curso en un entorno reproducible.

## Contenidos

- Hechos estilizados de los ciclos económicos  
- Modelo neoclásico dinámico  
- Consumo y ahorro intertemporal  
- Equilibrio general  
- Política fiscal y equivalencia ricardiana  
- Política monetaria intertemporal  
- Coordinación de políticas económicas  

## Herramientas

Durante el curso se utilizan herramientas como:

- Python
- Matlab  
- LaTeX  
- Excel  

Además de bases de datos públicas como DANE, Banco de la República, Banco Mundial y FMI.
